## 時間次元（0〜6）
下のバーに「時間次元」スライダーを足しました。
- t₁〜t₆ の各時間軸が、それぞれ自分の時計を持ちます。
- 再生／一時停止と、時計のリセットができます。
- 軸ごとの速さは −3〜3 倍の範囲で、「表示」パネルで変えられます。

物理サンプルの動きは、それぞれ決まった時間軸に結び付けてあります。時間次元を増やすほど、動きが1つずつ加わります。物理サンプルを出すと、時間次元が0なら自動で1になります。

## 式による形状の追加
プリミティブのボタンと同じ並びに「ƒ 式で作る…」を足しました。押すと式の入力ウインドウが開きます。書いた内容から、次の2種類のどちらかを自動で判断します。

- **パラメトリック**：`u = 0..2pi, 64` のような範囲を書いた行があると、こちらになります。
  - パラメータが1つなら曲線、2つなら曲面、3つ以上なら立体の格子になり、線だけの形（ワイヤーフレーム）です。
  - 何次元でも作れます。座標は x, y, z, w のほか、x1〜x20 で任意の軸を指定できます。
  - 輪のように閉じた形は、端が自動でつながります。
- **一次不等式**：`-1 <= x <= 1` や `x + y + z + w <= 1.5` のような条件を並べると、すべてを満たす範囲が中身の詰まった立体になります。ブーリアンや断面表示にもそのまま使えます。
- **共通の機能**
  - `r = 2` のような定数、sin や sqrt などの関数、`2pi` のような掛け算記号の省略、`#` で始まるコメントが使えます。
  - 式に時間の変数 `t1`〜`t6` を入れると、時間次元に合わせて形が動きます（例：動く平面で切られる立方体）。
- **例**：トーラス、クリフォード・トーラス（4D）、メビウスの帯、進む波、不等式で作る4次元単体と5次元立方体など、8つを用意しました。
- **エラー表示**：「2行目：「)」が足りません」のように行番号付きで出ます。範囲が閉じていない、条件を満たす点がない、一次式でない、なども知らせます。
- **再編集**：選んだ式の形状は「式を編集」で書き直せます。
- **ヘルプ**：書き方と例を「？」に追加しました（7言語）。
