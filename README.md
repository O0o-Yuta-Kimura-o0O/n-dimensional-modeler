# n次元モデラー / N-Dimensional Modeler

**v0.0.0** — 空間の次元をスライダーで 0〜10（上限変更可、最大20）に切り替えながら、多次元の形状を作り、眺め、変形し、ブーリアン演算できるモデラー兼ビューワー。

A modeler/viewer for polytopes in any dimension. Drag a slider to change the dimension of space (0–10 by default, adjustable up to 20) at any time without losing data.

## 機能 / Features

- **次元スライダー**：0〜上限。次元を下げても高次元の座標は保持され、非表示になるだけ（戻せば元通り）。
- **プリミティブ**：点、単体、超立方体、正軸体、正多角形（辺数 p）、多角柱、多角錐、デュオプリズム {p}×{q}、正24胞体、超球（ワイヤー）。現在の次元で生成。
- **操作**（マウス／タッチ）：視点回転（高次元軸を含む平面での回転も可）、形状移動、頂点編集。「移動方向」で1軸に固定すれば、見えない次元へも押し出せる。ピンチ／ホイールでズーム、2本指／右ドラッグでパン。
- **変形**：任意の座標平面での回転、拡大縮小、軸方向の伸縮、複製、削除、色。
- **n次元ブーリアン**：和・積・差（A−B）と合体（単純結合）。どの次元でも動作。
- **表示**：投影（透視／平行）と断面（隠れた座標＝断面位置での切り口）。奥行き色（4軸目以降の座標で着色）、軸ギズモ、自動回転。
- **多言語UI**：日本語・English・简体中文・한국어・Español・Français・Deutsch（ブラウザ言語を自動検出）。
- 元に戻す／やり直し、自動保存（localStorage）、JSON 書き出し／読み込み。
- キーボード：`Ctrl/⌘+Z` 元に戻す、`Ctrl/⌘+Shift+Z` やり直し、`↑/↓` 次元±1、`1/2/3` ツール切替、`Delete` 削除、`Esc` 選択解除。

## 仕組み / How it works

- `src/core/linalg.ts` — 任意次元の線形代数（Gram–Schmidt、アフィン包など）。
- `src/core/primitives.ts` — 組合せ構造（頂点・辺・ファセット）付きのプリミティブ生成。直積・錐を汎用的に構成。
- `src/core/polytope.ts` — 凸セルエンジン。各立体を凸セルの和として持ち、ファセットは頂点インデックスで保持（平面方程式は毎回頂点から再計算するので、頂点を動かしてもブーリアンが使える）。辺は「u, v を両方含む支持平面の全てに乗る他の頂点が無い」という組合せ判定で求めるため、どの次元・平坦な形（7次元空間中の多角形など）でも動く。
  - A∩B：A を B の全半空間（とアフィン包の等式）で切る
  - A−B：凸分割 ⋃ᵢ A∩{h₁≤0…hᵢ₋₁≤0}∩{hᵢ≥0}
  - A∪B：A ∪ (B−A)
  - 表示用の辺は境界ピースを求めた上で、局所的に平坦な部分（凸分割の切れ目）を除去。
- `src/render/view.ts` — n→…→3 の入れ子透視投影と 3D カメラ。
- `src/ui/` — 状態管理・操作・パネル。`src/i18n/` — 翻訳辞書（`en.ts` のキーに合わせて追加するだけで言語を増やせる）。

## 既知の制限 (v0.0.0)

- ブーリアンの計算量は次元とともに急増します（目安：6次元の超立方体同士で約0.5秒、7次元以上は数秒以上）。計算中は画面が止まります。
- ブーリアン結果の辺に、T字接合による同一直線上の分割点が残ることがあります（見た目は同じ）。
- 頂点編集で面が平面でなくなった場合、ブーリアンでは各ファセットを近似平面として扱います。
- 超球はワイヤーフレームのみ（ブーリアン・断面の対象外）。
- 面の塗りつぶしは未対応（ワイヤーフレーム表示）。
