# n次元モデラー / N-Dimensional Modeler

**v0.3.1** — 空間の次元をスライダーで 0〜10（上限変更可、最大20）に切り替えながら、多次元の形状を作り、眺め、変形し、ブーリアン演算できるモデラー兼ビューワー。

A modeler/viewer for polytopes in any dimension. Drag a slider to change the dimension of space (0–10 by default, adjustable up to 20) at any time without losing data.

**▶ Web版 / Live demo: https://o0o-yuta-kimura-o0o.github.io/n-dimensional-modeler/**

## 機能 / Features

- **次元スライダー**：0〜上限。次元を下げても高次元の座標は保持され、非表示になるだけ（戻せば元通り）。
- **プリミティブ**：点、単体、超立方体、正軸体、正多角形（辺数 p）、多角柱、多角錐、デュオプリズム {p}×{q}、正24胞体、超球（ワイヤー）。現在の次元で生成。
- **物理・量子サンプル**（ボタン一発、ネイティブ次元と見やすい視点に自動で切替）：
  | サンプル | 次元 | 内容 |
  |---|---|---|
  | 光円錐 | 4D | 特殊相対論。空間 x,y,z＋時間 t（w軸）。3次元の断面で、光の波面＝半径 \|t\| の球 |
  | ホップ・ファイブレーション | 4D | 1量子ビットの状態空間 S³ → ブロッホ球 S²。どの2つの円も絡み合う |
  | カラビ・ヤウ多様体 | 4D | 超弦理論。5次曲面 z₁⁵+z₂⁵=1 の実4次元断面 |
  | 準結晶 | 6D | 切断・射影法の6次元立方体。3次元への影が菱形三十面体 |
  | E8（ゴセット 4₂₁） | 8D | 頂点240・辺6720・ファセット19440。ペトリー投影で表示 |
  | 超弦理論の時空 | 10D | 4次元時空 × 6次元コンパクト空間（T⁶ で簡略化） |
- **時間次元（0〜6）**：独立した時間軸 t₁〜t₆ を追加。各軸に時計と速さがあり、再生／一時停止／リセット可能。物理サンプルには時間軸ごとのアニメーションが入っていて、時間次元を増やすほど動きが加わります（光円錐：収束→拡散する光の波面＋ローレンツブースト、ホップ：ブロッホ球の回転、カラビ・ヤウ：射影角の回転、準結晶：フェイゾン、E8・10次元時空：6本の時間軸すべてを使用）。動いている形状も編集・ブーリアン可能（ブーリアンは現在の姿勢で固定）。
- **式で作る**：プリミティブ一覧の「ƒ 式で作る…」から式を入力して形状を追加。
  - パラメトリック（`x = cos(u)` … `u = 0..2pi, 64`）：曲線・曲面・格子を任意の次元で（ワイヤーフレーム）。
  - 一次不等式（`-1 <= x <= 1`、`x + y + z + w <= 1.5` …）：凸多胞体の立体（ブーリアン・断面に使用可）。
  - 定数、関数、`t1`〜`t6`（時間次元の時計）に対応。時間を使う式は再生中に毎フレーム作り直されます。書き方は「？」ヘルプに記載。行番号付きのエラー表示。
- **テーマ11種**（言語の横で切替）：ダーク／ライト／ブループリント（製図・等幅）／墨（和紙・明朝・朱）／ネオン（加算発光）／オブシディアン＆ゴールド（ディドン体）／ノルド（北極）／桜／スイス（国際様式）／ターミナル（緑の蛍光管）／夕焼け。UI配色だけでなくフォント・線の太さ・発光・インク調の色付けまで切り替わります。
- **操作**（マウス／タッチ）：視点回転（高次元軸を含む平面での回転も可）、形状移動、頂点編集。「移動方向」で1軸に固定すれば、見えない次元へも押し出せる。ピンチ／ホイールでズーム、2本指／右ドラッグでパン。
- **変形**：任意の座標平面での回転、拡大縮小、軸方向の伸縮、複製、削除、色。
- **n次元ブーリアン**：和・積・差（A−B）と合体（単純結合）。どの次元でも動作。
- **表示**：投影（透視／平行）と断面（隠れた座標＝断面位置での切り口）。奥行き色（4軸目以降の座標で着色）、軸ギズモ、自動回転。
- **多言語UI**：日本語・English・简体中文・한국어・Español・Français・Deutsch（ブラウザ言語を自動検出）。
- 元に戻す／やり直し、自動保存（localStorage）、JSON 書き出し／読み込み。
- キーボード：`Ctrl/⌘+Z` 元に戻す、`Ctrl/⌘+Shift+Z` やり直し、`↑/↓` 次元±1、`1/2/3` ツール切替、`Delete` 削除、`Esc` 選択解除。

## 仕組み / How it works

- `src/core/linalg.ts` — 任意次元の線形代数（Gram–Schmidt、アフィン包など）。
- `src/core/primitives.ts` — 組合せ構造（頂点・辺・ファセット）付きのプリミティブ生成。直積・錐を汎用的に構成。
- `src/core/polytope.ts` — 凸セルエンジン。各立体を凸セルの和として持ち、ファセットは頂点インデックスで保持（平面方程式は毎回頂点から再計算するので、頂点を動かしてもブーリアンが使える）。辺は「u, v を両方含む支持平面の全てに乗る他の頂点が無い」という組合せ判定で求めるため、どの次元・平坦な形（7次元空間中の多角形など）でも動く。
  - A∩B：A を B の全半空間（とアフィン包の等式）で切る
  - A−B：凸分割 ⋃ᵢ A∩{h₁≤0…hᵢ₋₁≤0}∩{hᵢ≥0}
  - A∪B：A ∪ (B−A)
  - 表示用の辺は境界ピースを求めた上で、局所的に平坦な部分（凸分割の切れ目）を除去。
- `src/core/physics.ts` — 物理・量子サンプル（E8 のルート系とペトリー平面、正二十面体の切断・射影基底など）。`src/core/sliceWorker.ts` — 断面計算用 Web Worker。
- `src/core/expr.ts` — 安全な数式パーサ（eval 不使用）。`src/core/formula.ts` — 式からの形状生成（パラメトリック格子／不等式からの凸多胞体）。
- `src/core/anim.ts` — 時間次元アニメーション（各トラックを時間軸に結び付けたアフィン変換。逆変換で編集を元座標へ戻す）。
- `src/render/theme.ts` — テーマ定義（CSS変数＋キャンバス描画パラメータ。フォントはシステムフォントのみでオフライン動作）。
- `src/render/view.ts` — n→…→3 の入れ子透視投影と 3D カメラ。
- `src/ui/` — 状態管理・操作・パネル。`src/i18n/` — 翻訳辞書（`en.ts` のキーに合わせて追加するだけで言語を増やせる）。

## 既知の制限 (v0.0.0)

- ブーリアンの計算量は次元とともに急増します（目安：6次元の超立方体同士で約0.5秒、7次元以上は数秒以上）。計算中は画面が止まります。
- ブーリアン結果の辺に、T字接合による同一直線上の分割点が残ることがあります（見た目は同じ）。
- 頂点編集で面が平面でなくなった場合、ブーリアンでは各ファセットを近似平面として扱います。
- 超球・ホップ・ファイブレーション・カラビ・ヤウはワイヤーフレームのみ（ブーリアン・断面の対象外）。
- 断面はバックグラウンド（Web Worker）で計算するので画面は止まりませんが、E8 のようにファセットが非常に多い形状は時間がかかります（目安：3次元断面 約1.5秒、4〜5次元断面 数秒〜）。
- 面の塗りつぶしは未対応（ワイヤーフレーム表示）。
